alignment module¶

Image Alignment Module

This module provides functionality for aligning images using feature detection, descriptor extraction, matching, and homography computation with OpenCV.

It supports various keypoint detectors (ORB, SIFT), matching methods, and homography estimation techniques for image stitching and alignment tasks.

alignment.feature_detector_extractor(type, gray, nb)¶

Detect keypoints and compute descriptors using specified detector.

Parameters:

  • type (str) – Type of detector (‘ORB’ or ‘SIFT’).

  • gray (numpy.ndarray or None) – Grayscale image.

  • nb (int) – Number of keypoints to detect.

Returns:

Tuple of keypoints and descriptors.

Return type:

tuple(list or None, numpy.ndarray or None)

alignment.matcher(type, desc1, desc2, alpha)¶

Match descriptors using Brute Force matcher with filtering.

Parameters:

  • type (str) – Norm type for matching.

  • desc1 (numpy.ndarray or None) – Descriptors from first image.

  • desc2 (numpy.ndarray or None) – Descriptors from second image.

  • alpha (float) – Multiplier for distance threshold.

Returns:

Filtered list of matches.

Return type:

list or None

alignment.compute_homography(kp1, kp2, matches, method)¶

Compute homography matrix from matched keypoints.

Parameters:

  • kp1 (list) – Keypoints from first image.

  • kp2 (list) – Keypoints from second image.

  • matches (list) – List of matches.

  • method (str) – Homography estimation method.

Returns:

Homography matrix and mask.

Return type:

tuple(numpy.ndarray or None, numpy.ndarray or None)

alignment.save_fused_image(img1, img2, M, name='fused_image.jpg')¶

Save a fused image by warping img1 onto img2 using homography.

Parameters:

  • img1 (numpy.ndarray) – First image.

  • img2 (numpy.ndarray) – Second image.

  • M (numpy.ndarray) – Homography matrix.

  • name (str) – Output filename.

alignment.align_image(img1, img2, args)¶

Align two images using feature detection and homography.

Parameters:

  • img1 (str) – Path to first image.

  • img2 (str) – Path to second image.

  • args (dict) – Dictionary of arguments.

Returns:

Aligned image or None if failed.

Return type:

numpy.ndarray or None
