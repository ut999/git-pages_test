crack_processing module¶

crack_processing Module

This module provides functionality for detecting and measuring cracks in images using image processing techniques. It includes watershed segmentation, skeletonization, and metric calculations for crack analysis.

crack_processing.find_scale(img, scale=200, crop_factor=50)¶

Computes a pixel‑to‑unit scale factor by detecting the longest horizontal run of black pixels in a cropped binary image.

Parameters:

  • img_path (str) – Path to the input image.

  • scale (float) – Reference physical size or unit length used to compute the final scale factor. Defaults to 200.

  • crop_factor (int) – Factor controlling how much of the image border is cropped. The image is cropped by width//crop_factor and height//crop_factor. Defaults to 50.

Returns:

Computed scale factor defined as scale / longest_run.

Return type:

float
